# BSON Mapper / Unmapper

Собственная реализация сериализации и десериализации BSON на Python.

## Что сделано

- реализованы функции `marshal(data)` и `unmarshal(data)`
- добавлена поддержка `int32`, `int64`, `double`, `string`, `bool`, `null`
- добавлена поддержка `bytes`, `bytearray` и `datetime`
- поддержаны вложенные `dict`, `list` и `tuple`
- сделана детерминированная сериализация словарей с сортировкой ключей
- реализована проверка циклических ссылок
- добавлена строгая обработка ошибок при marshal / unmarshal
- добавлены специализированные исключения для битых данных, переполнений и неподдерживаемых типов

## Поддерживаемые возможности

Библиотека умеет:

- сериализовать Python-структуры в BSON-байты
- восстанавливать BSON-документы обратно в Python-объекты
- различать `int32` и `int64` по диапазону значения
- хранить бинарные данные через BSON binary subtype `0`
- переводить `datetime` в `UTC` и хранить в миллисекундах от Unix epoch
- работать со вложенными документами и массивами
